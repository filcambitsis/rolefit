# Presenting RoleFit

## A 90-second walkthrough

1. Start `make demo`. Clearly identify the fictional CV and job listings.
2. Show role discovery and preferences.
3. Open a job and explain the score, an exact supporting CV quote, and an unverified requirement.
4. Save the role and open Saved jobs.
5. Explain the real flow: PDF/DOCX/TXT parsing, public employer feeds, SQLite/PostgreSQL storage and transparent matching rules.
6. Close with the limitation: this is a portfolio prototype with partially reviewed matching, not a validated hiring predictor.

The demo snapshot is generated by the real Python matching code. Its fixed sample data avoids a separate browser implementation and needs no live backend.

## CV bullet

Built RoleFit, a full-stack app matching CVs to Dutch AI, data and software jobs using FastAPI, Next.js and SQLAlchemy, integrating public employer feeds and requirement coverage linked to exact CV passages.

## Interview points

- Why coverage and hiring probability are different.
- How related computing degrees and completion dates are checked without guessing specialised experience.
- Why failed extraction has no score rather than zero.
- How failed source fetches preserve stored jobs.
- How exact evidence, user isolation and CV deletion work.
- Why optional model extraction, skip lists and the background crawler were removed to keep the project understandable.

Demo screenshots in `docs/images/` are presentation assets, not validation results. Use fictional data when updating them.
